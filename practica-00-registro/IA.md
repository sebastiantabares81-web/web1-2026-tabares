# Declaración de uso de IA

## Herramientas utilizadas

No se utilizó inteligencia artificial para realizar esta práctica, ya que hasta el momento solamente se realizó la creación y configuración del repositorio de GitHub solicitado para el curso.

## Uso de IA

No se utilizó IA para generar código, resolver ejercicios o desarrollar contenido de la práctica. La actividad realizada corresponde únicamente a la configuración inicial del repositorio, la creación de la rama y la organización de los archivos necesarios para futuras prácticas.

## Motivo

La práctica todavía no ha sido desarrollada, por lo tanto no fue necesario utilizar herramientas de inteligencia artificial para realizarla.
